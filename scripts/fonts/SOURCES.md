# Fonts

`../lib/glyphs.json` holds outlines derived from these fonts, all under the SIL Open Font License 1.1
(licence texts beside this file). The TTFs are not committed; download them here to run `npm run fonts`.

- JetBrains Mono 2.304 (Regular, Bold): https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304
- Inter 4.1 (Regular, SemiBold, from `extras/ttf`): https://github.com/rsms/inter/releases/tag/v4.1
- Unbounded 1.701 (ExtraBold): the static, unhinted `Unbounded-ExtraBold.ttf` from the Google Fonts
  download (https://fonts.google.com/specimen/Unbounded). The hinted file in
  https://github.com/googlefonts/unbounded has slightly different outlines.
